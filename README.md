# Fr.eeeeZe Music Lab — Prototype 0.1

這是一個可直接部署到 GitHub Pages 的單頁互動原型，不需要安裝 Node.js 或其他套件。

## 目前可操作功能
- 互動五度圈：選擇 12 個大調，顯示相對小調與調號
- 大調／小調切換
- 七級和弦概覽
- 流行、爵士、電影感、混合調式和弦進行生成
- 瀏覽器 Web Audio 和弦試聽
- 手機響應式版面

## 部署到 GitHub Pages
1. 將 `index.html` 與 `README.md` 上傳到 GitHub repository 的根目錄。
2. 開啟 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
5. 等待 GitHub Pages 部署完成，頁面網址通常是 `https://你的帳號.github.io/你的repo名稱/`。
